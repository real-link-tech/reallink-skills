# Streaming Pool JSON HTML

Use this skill when the user provides an Unreal texture streaming pool report generated by `r.Streaming.PoolReport.Start/Stop` and asks for a chart or HTML visualization.

The default chart shows:

- Blue: `requiredPoolMB`
- Green: `streamingPoolMB`
- Purple: `usedStreamingPoolMB`
- Red: `overBudgetMB`

## Workflow

1. Locate the input report. Prefer a user-provided path; otherwise search for `streaming_pool_report_*.ndjson`.
2. Generate the chart with the bundled script:

```powershell
python .\scripts\streaming_pool_json_to_html.py "path\to\streaming_pool_report.ndjson"
```

3. If the script is run from outside the skill folder, use the absolute script path:

```powershell
python "D:\UnrealEngine\.codex\skills\streaming-pool-json-html\scripts\streaming_pool_json_to_html.py" "path\to\streaming_pool_report.ndjson"
```

4. Give the user the generated `.html` path and summarize the key peak values from the script output.

## Useful Options

```powershell
python .\scripts\streaming_pool_json_to_html.py "report.ndjson" --output "report.html"
python .\scripts\streaming_pool_json_to_html.py "report.ndjson" --title "B02 Texture Streaming"
python .\scripts\streaming_pool_json_to_html.py "report.ndjson" --fields requiredPoolMB,streamingPoolMB,wantedMipsMB,cachedMipsMB
python .\scripts\streaming_pool_json_to_html.py "report.ndjson" --max-points 2500
```

## Data Notes

- Input is newline-delimited JSON, one object per line.
- `{"type":"start", ...}` and `{"type":"stop", ...}` describe the capture.
- `{"t":"s", ...}` rows are per-frame samples.
- `{"type":"summary", ...}` may contain max values and `recommendedEffectiveStreamingPoolMB_RequiredX1_3`.
- The x-axis uses elapsed seconds `e` when available, falling back to frame `f`.
- The output HTML is self-contained and can be opened directly in a browser.
